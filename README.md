# DA6401 – Deep Learning Project Portfolio

This repository serves as a consolidated portfolio of deep learning projects completed as part of the **DA6401: Introduction to Deep Learning** course.

Instead of isolated assignments, this collection highlights the implementation of core deep learning systems across architectures, training strategies, and evaluation workflows.

---

## 📌 Project Overview

### 🔹 Neural Networks from Scratch

**Repository:** https://github.com/ak4off/da6401_assignment1

* Implemented fully-connected neural networks using **NumPy only**
* Built forward and backward propagation from first principles
* Explored optimization techniques and loss functions

---

### 🔹 Convolutional Neural Networks & Optimization

**Repository:** https://github.com/ak4off/da6401_assignment2

* Designed and trained CNN architectures for image classification
* Performed **hyperparameter sweeps using Weights & Biases**
* Investigated effects of regularization, dropout, and architecture choices

---

### 🔹 Sequence-to-Sequence Learning with Attention

**Repository:** https://github.com/ak4off/da6401_assignment3

* Implemented **RNN, LSTM, and GRU-based encoder-decoder models**
* Integrated **attention mechanisms** for improved sequence modeling
* Applied to **transliteration using the Dakshina dataset**
* Visualized attention maps and analyzed model behavior

---
